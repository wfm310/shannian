## 3. 字段真值

| 字段 | 必填 | 规则 |
|---|---|---|
| 任务标题 | 是 | 标准模式继承选题标题；即兴模式自动提取文案前 15 字 |
| 生产模式 | 是 | 标准模式 / 即兴模式 |
| 关联选题 | 条件必填 | 标准模式创建时必填；即兴模式补填时自动创建入库 |
| 当前阶段 | 是 | 上表 6 态，自动流转 |
| 关联框架 | 条件必填 | 脚本撰写阶段必填（含即兴补填），含版本号 + 结构快照 |
| 阶段产出物 | 自动 | JSON 按阶段 key 存储选题记录/脚本文档/素材清单/成片/发布移交 |
| 待补填阶段 | 自动 | 即兴模式待补填列表 |
| 负责人 | 是 | 峰岚 / 佳韵；支持转交并记录历史（转交后原负责人只读） |
| 创建时间 / 发布时间 | 自动 | — |

### 阶段产出物要点

- 选题确认：选题ID + 标题快照 + 来源（选题库/即兴创作）+ 内容参考快照 + 补填状态
- 脚本撰写：框架ID + 版本号 + 结构快照 + 脚本内容（按框架步骤填入）
- 拍摄/制作：素材列表（名称/类型：视频·音频·图片·文本·其他/文件引用/时长/备注）
- 剪辑：成片名称 + 文件引用 + 时长 + 分辨率 + 备注
- 发布：移交时间 + 制作发布记录ID + 发布确认时间（回写）

## 4. 状态流转（即阶段推进）

| 当前 | 触发 | 下一 | 系统动作 |
|---|---|---|---|
| — | 新建（标准） | 选题确认 | 关联选题，标题继承，生成 P2 待办 |
| — | 新建（即兴） | 脚本撰写 | 选题确认标记「待补填」，生成 P2 待办 |
| 脚本撰写（待补填） | 补填选题+框架 | 脚本撰写 | 新选题入库（已生产 · 来源=即兴创作），文案同步选题内容参考 |
| 脚本撰写 | 完成脚本 | 拍摄/制作 | 脚本存档，生成拍摄待办 |
| 拍摄/制作 | 完成 | 剪辑 | 素材存档，生成剪辑待办 |
| 剪辑 | 完成 | 待发布 | 成片存档，移交制作发布，生成发布待办 |
| 待发布 | 制作发布确认发布 | 已发布 | 写入发布记录，数据追踪启动 |

- 每进入新阶段自动生成 P2 指向性待办；长期停滞靠待办自动延期（最多 3 次，之后标记逾期）推动
- 即兴模式：进入拍摄/制作前必须完成补填（系统拦截）；即兴内容自动回流灵感库标记「即兴创作」

## 5. 跨模块转化映射

| 方向 | 映射 | 规则 |
|---|---|---|
| 选题库 → 生产 | 选题标题→任务标题；文案内容参考→文案内容；人群/问题/方法→参考上下文 | 已确认选题自动创建，1:1 |
| 框架库 → 生产 | 选框架时记录版本号 + 结构快照（版本锁定） | 脚本撰写必选 |
| 生产 → 制作发布 | 待发布阶段移交，自动创建发布记录 | 见 13-制作发布 |
| 生产 → 灵感记录 | 即兴内容回流，来源=即兴创作 | 自动 |
