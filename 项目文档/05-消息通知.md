# 05-消息通知

> 统一消息中心：所有模块的通知汇总在此，三态流转（未读/已读/已处理）驱动处理节奏；通知不可删除、不可主动忽略。

> 收编自：消息通知-字段规范（2026-08-23，以此为准）+ A1 第二节触发场景，按总纲骨架重写。

## 1. 页面场景与画板清单（预估 3 张）

| 端 | 画板 | 说明 |
|---|---|---|
| PC | 消息页 | 独立页面，按类型分组完整列表 |
| PC | 铃铛下拉 + 详情弹窗 | 顶栏入口交互态（下拉浮层 + 点击详情 Dialog） |
| APP | 消息页 | 分组列表 |

新消息 toast（Sonner，右上角，3-5 秒自动消失）为交互态，随消息页画板附注。

## 2. 三个展示入口

| 入口 | 位置 | 规则 |
|---|---|---|
| 顶栏铃铛下拉 | Topbar 右侧铃铛 | 显示最新 5 条**未读**，时间倒序；底部「查看全部」跳消息页；有未读显示数字角标（1-9 显示数字，9+ 显示「9+」，0 不显示）；点击单条=标记已读+开详情 |
| 独立消息页 | `/notification` | 按类型分组的完整列表；组内时间倒序；未读带左侧圆点；已处理灰色折叠（Collapsible），点击展开 |
| 新消息 toast | 右上角 | 页面加载检测到新通知或当前操作触发新通知时弹出；点击打开详情 Dialog；不替代其他入口 |

## 3. 消息类型（3 大类）

| 类型 | 值 | 触发场景（收编自各模块 + A1） |
|---|---|---|
| 待办通知 | `todo` | 新任务分配（**含总纲规则 9 分配通知**）、任务被接受、任务完成、优先级自动升阶、任务自动归档 |
| 模块通知 | `module` | 对标拆解完成/转化、选题评估通过、生产阶段推进、发布确认、数据节点到期、数据异常检测命中、闪念超 48h、复盘触发、AI 洞察推送 |
| 系统通知 | `system` | 数据同步完成、AI 模型加载、系统更新、归档完成 |

关联模块枚举：todo / benchmark / topic / production / publish / dashboard / review / flash-thought / inspiration / ai-module / system（新增模块追加即可）。

## 4. 字段真值

| # | 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| 1 | 通知标题 | string | 是 | 一句话概括，如「你有一条新待办任务」「这条对标拆解由你来负责」 |
| 2 | 通知类型 | 枚举 | 是 | todo / system / module |
| 3 | 简要内容 | string | 是 | 列表和详情展示的描述 |
| 4 | 关联模块 | 枚举 | 是 | 点击跳转的目标模块 |
| 5 | 关联 ID | number/null | 是 | 关联记录主键；系统通知为 null |
| 6 | 接收人 | string | 是 | 接收人昵称（动态注册账号）；系统类可发全体 |
| 7 | 状态 | 枚举 | 是 | unread / read / handled |
| 8 | 通知时间 | number | 是 | 系统自动 |

## 5. 状态流转

| 当前 | 触发 | 下一 | 触发方 |
|---|---|---|---|
| — | 新通知生成 | 未读 | 系统 |
| 未读 | 用户点击（下拉/列表/toast） | 已读 | 用户 |
| 已读 | 关联模块对应记录完成 | 已处理 | **系统自动判定**，用户不能手动标 |

核心约束：通知不可删除（永久保留）；无「已忽略」；已处理自动折叠。

## 6. 类型色映射（主题 token）

| 类型 | 色 |
|---|---|
| todo 待办通知 | 黄 250,204,21（需行动） |
| module 模块通知 | 紫 139,92,246（流转） |

## 7. 统一发送 API（开发约定）

所有模块发通知调同一函数（`src/lib/notification.ts` 的 `sendNotification`），自动完成存库 + toast；保证格式统一、逻辑单点维护。各模块通知触发场景见各模块文档第 5 节（本文档不重复维护）。

## 8. 演示数据（新增设定）

- 铃铛角标 3；下拉显示 3 条未读：「你有一条新待办任务」（todo）、「这条对标拆解由你来负责」（module·benchmark）、「《口播技巧：开头 3 秒定生死》数据异常提醒」（module·dashboard）
- 消息页分组：待办 2 / 模块 5 / 系统 1，其中已处理 1 条折叠

## 9. 全局规则引用

通知不可删除（全局无删除延伸）；接收人=动态注册账号；详情「前往查看」跳关联模块；UI 组件强制 shadcn（Base-UI Rhea）：Dialog / DropdownMenu / Sonner / Collapsible / Badge。
