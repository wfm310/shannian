# 01-登录页

> 系统入口：只有登录没有注册，双账号小团队；账号由管理员在 Supabase 后台创建，新账号首次登录强制进引导页。

## 1. 页面场景与画板清单

| 端 | 画板 | 说明 |
|---|---|---|
| PC | 登录页 1920 | 品牌区（logo 7:1048 / 5:203）+ 登录表单 |
| APP | 登录页 390 | 同构精简 |

> 旧登录页组件已移入「归档-旧组件」页，重设计不引用。

## 2. 字段真值

| # | 字段 | 必填 | 规则 |
|---|---|---|---|
| 1 | 账号 | 是 | 邮箱或昵称选择（已注册账号列表，头像+昵称可点选） |
| 2 | 密码 | 是 | Supabase Auth 校验 |
| 3 | 记住登录 | 否 | 默认勾选 |

- 无「注册」入口、无忘记密码自助流程 ⚠（忘记密码走管理员重置，待逐条过确认）
- 新成员账号添加方式：管理员在 Supabase 后台创建 ⚠ 待确认（是否需要在设置页内做「添加成员」）

## 3. 状态流转

| 状态 | 触发 | 系统动作 |
|---|---|---|
| 未登录 | 打开应用（未记住登录） | 停留登录页 |
| 登录成功 | 账号密码校验通过 | 首次登录 → 引导页；非首次 → 首页工作台 |
| 登录失败 | 校验失败 | 表单错误提示，不清空已输账号 |

## 4. 跨模块转化映射

无。

## 5. 消息通知触发点

无（登录不发通知；异常登录提醒 ⚠ 暂不做，待确认）。

## 6. 演示数据

峰岚 / 佳韵 双账号（占位昵称，总纲规则 1）。

## 7. 全局规则引用

全局禁止 Emoji（原则 5）；UI 组件 shadcn（原则 6）；负责人=动态注册账号（规则 1，本页是账号体系的入口）。
