# 06-闪念池

> 快记念头 + Obsidian 式力导向星图：念头先进池，48h 内处理；归类三选一（转待办 / 转灵感 / 转问答）；关键词成恒星、闪念成行星，已处理节点灰化保留可查去向。

## 2. 字段真值

### 2.1 快记

| 字段 | 必填 | 说明 |
|---|---|---|
| 闪念内容 | 是 | 快记原文，一句话；回车保存，**保存后不可编辑、无删除** |
| 捕捉时间 | 自动 | 系统时间 |

### 2.2 节点处理（归类）

| 字段 | 必填 | 说明 |
|---|---|---|
| 你的想法 | **是** | 归类时填的那句话，随闪念一起带入目标模块（选题描述 / 灵感思考第一条 / 任务描述 / 触发场景说明） |
| 归类去向 | 是 | 三选一：转待办 / 转灵感 / 转问答 |
| 关键词 | 自动 | AI 提取（Ollama），决定星图归属恒星 |

## 3. 状态流转

| 状态 | 色 | 触发 | 系统动作 |
|---|---|---|---|
| 待处理 | 青绿点 | 快记成功 | — |
| 超 48h | 橙色描边 | 快记成功且 48h 未处理 | 消息提醒「有 1 条闪念超 48h 未处理」 |
| 已转待办 | 终态节点灰化（灰 120,130,145） | 转待办成功 | 节点灰化缩小 + 高亮圈，点击打开终态去向 |
| 已归类 | 终态节点灰化（灰 120,130,145） | 转灵感 / 转问答成功 | 同上 |

- 转化只能一次（总纲规则 4）；「已转待办 / 已归类」= 总纲「已转化」终态在闪念池的场景化命名
- 已处理节点**保留在星图中**，灰化缩小不消失，可点击打开「终态节点去向」跳转目标模块

## 4. 跨模块转化映射（三选一，只能一次）

| 去向 | 字段映射 |
|---|---|
| 转待办 | 任务名称←闪念内容 / 任务详情←你的想法 / 负责人·关联模块·进度目标数必选填 / 截止默认明天 20:00 / P2（详见 04 §4.1） |
| 转灵感 | 灵感标题←闪念内容（预填可编辑精简）/ 思考过程第一条←你的想法 / 结论空 / 分类默认「其他」/ 来源区完整保留闪念原文 +「查看闪念›」（详见 09 §4.1） |
| 转问答 | 问题内容←闪念内容 / 问题来源=闪念转入 / 来源详情←你的想法（触发场景说明）/ 答案空（详见 08 §4） |

## 5. 消息通知触发点

| 事件 | 消息 |
|---|---|
| 快记成功 | 无消息（静默，toast 即可） |
| 超 48h 未处理 | 「有 1 条闪念超 48h 未处理」（module·flash-thought） |
| 归类成功 | 无消息中心通知（星图/列表即时更新 + toast）⚠ 待逐条过确认 |

## 6. 演示数据（故事线）

- 主角闪念：「口播开头用反常识结论，前 3 秒留住人」→ 已归类（转灵感《口播开头用反常识结论，前 3 秒留住人》）
- 池内统计：待处理 15 · 超 48h 5 · 已归类 8 · 已转待办 4

## 7. 全局规则引用

无删除仅归档（规则 6）；快照拷贝 / 转化只能一次（规则 4）；「你的想法」术语（第二节）；视图例外=星图+列表双视图（规则 12）。
