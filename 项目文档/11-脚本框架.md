## 2. 五种结构类型（固定，不可新增/删除/改名）

| 结构类型 | 适用场景 | 结构流程 |
|---|---|---|
| ① 标准干货型（主力） | 教方法、讲流程 | 抛观点 → 举例佐证 → 给方法 → 引导 |
| ② 故事案例型 | 讲学员案例、踩坑经历 | 抛悬念/场景 → 展开冲突 → 揭示转折/方法 → 引导 |
| ③ 纠错对比型 | "90%的人都做错了"类 | 展示错误做法 → 为什么错 → 正确做法 → 引导 |
| ④ 清单盘点型 | "5个标准""3个工具"类 | 抛主题 → 第1点 → 第2点 → 第3点 → 总结+引导 |
| ⑤ 问答拆解型 | 回应评论区高频问题 | 模拟提问 → 分析为什么 → 给解答 → 引导 |

> 与「07-对标拆解」维度 3 的内容结构类型共享同一套定义，保证拆解→框架→生产全链路一致。每种类型下可有多个框架实例；步骤数不设上下限，支持增删。

## 3. 字段真值

| 字段 | 必填 | 规则 |
|---|---|---|
| 框架名称 | 是 | — |
| 框架类型 | 是 | 5 类型之一 |
| 结构定义 | 是 | 分步骤 JSON：步骤序号 + 步骤名称 + 内容描述 |
| 适用场景 | 否 | 内容类型标签 |
| 来源 | 是 | 对标拆解提炼 / 手动创建 / 灵感转化 |
| 来源关联ID | 否 | 转化时自动关联 |
| 版本号 | 自动 | 语义化 v主.次：增删步骤=主版本，调整描述=次版本 |
| 版本历史 | 自动 | 每版本含结构定义 + 修改说明 + 时间；不可删除，可回溯（不做 diff 对比） |
| 引用次数 | 自动 | 被制作发布引用的次数，初始 0 |
| 状态 | 是 | 草稿 / 使用中 / 已归档（停用） |
| 创建时间 / 创建人 | 自动 | — |

## 4. 状态流转

| 状态 | 色（主题 token） | 触发 → 下一状态 | 系统动作 |
|---|---|---|---|
| 草稿 | 灰 120,130,145 | 手动创建 / 拆解提炼 / 灵感转化入库 | 自动同步知识图谱 |
| 使用中 | 青绿 46,212,168 | 启用（条件：名称+类型+至少 1 步骤） | 可被拆解/生产/发布引用 |
| 使用中 | — | 迭代优化（修改说明必填） | 版本号递增，历史保留 |
| 已归档 | 弱灰 90,100,114 | 停用 | 引用处不受影响（版本锁定），不再出现在可选列表 |
| 已归档 → 使用中 | — | 重新启用 | 恢复可选 ⚠ |

⚠ **与总纲的冲突（需用户裁决）**：总纲规定「归档是唯一终态」，但旧 A7 允许已归档框架重新启用。本文按「**库类资源（脚本框架/常用标签）归档=停用可恢复；记录类内容（闪念/灵感/选题/发布/复盘）归档=终态**」处理。若你确认此区分，我会在总纲第三节补一条说明；若不允许恢复，本文状态流转改为单向。

## 5. 版本管理规则

- 引用版本锁定：制作发布 / 生产任务关联的框架版本锁定，后续迭代不影响已关联记录
- 来源入库：拆解提炼和灵感转化新增的框架自动入草稿，需完善后启用

## 6. 跨模块转化映射

| 方向 | 映射 | 规则 |
|---|---|---|
| 对标拆解 → 框架 | 仅同步类型 + 名称 | 入库草稿，步骤后续手动完善；拆解时也可引用现有框架作对照 |
| 灵感记录 → 框架 | 灵感标题→框架名称；思考过程摘要→参考备注；类型手动选 | 入库草稿 |
| 框架 → 对标拆解 | 只读引用，对照分析视频结构 | — |
| 框架 → 内容生产 | 脚本撰写阶段必选一个框架，记录版本号 + 结构快照（版本锁定） | — |
| 框架 → 制作发布 | 只读关联展示，供事后复盘追溯 | 引用次数 +1 |
