## 2. 字段真值（新建待办表单，转待办预填同构）

| # | 字段 | 必填 | 枚举 / 规则 |
|---|---|---|---|
| 1 | 任务名称 | 是 | 文本 |
| 2 | 任务详细介绍 | 是 | 多行文本 |
| 3 | 负责人 | 是 | 动态注册账号（总纲规则 1，占位 峰岚/佳韵）；**不指定不能创建**；头像色：峰岚=蓝紫、佳韵=红 |
| 4 | 关联模块 | 否 | 仅 3 个：对标拆解 / 选题库 / 制作发布（无「脚本框架」），**可多选**；多选时进度目标数的对应关系 ⚠ 待逐条过确认 |
| 5 | 进度目标数 | 关联模块后必填 | 正整数，单位「条」；配合已完成数算进度 |
| 6 | 初始优先级 | 是 | P0 必须干完 / P1 应该干完 / P2 本周内 / P3 有空再做；小注「按截止自动升阶」 |
| 7 | 截止日期 | 是 | 驱动优先级自动升阶；新建默认「今天 20:00」 |

详情只读字段：任务名称 / 任务详细介绍 / 当前优先级（升阶后实时值）/ 负责人 / 创建时间 / 截止日期 / 状态（自动更新）/ 任务来源（手动创建 / 闪念池转入等，自动显示）/ 关联模块 / 任务进度（已完成数/目标数）/ 完成时间。

## 3. 状态流转

| 状态 | 色（主题 token） | 触发 | 系统动作 |
|---|---|---|---|
| 待接受 | 黄 250,204,21 | 新建成功 | 给负责人发分配通知；负责人可接受 |
| 进行中 | 蓝（token） | 负责人点击「接受」 | 开始统计进度 |
| 已完成 | 青绿 46,212,168 | 已完成数 ≥ 目标数；无关联模块时手动勾选 | 当天 23:59 自动归档 |
| 已归档 | 弱灰 90,100,114 | 23:59 自动 | 终态 |

- **自动升阶**：随截止临近 P3→P2→P1→P0，升阶时给负责人发通知
- **进度统计（总纲规则 10）**：已关联模块的待办，已完成数 = 该待办负责人名下关联记录中完成类的数量（对标拆解 = 已拆解/已转化；选题库 = 已确认；制作发布 = 已发布）；**记录负责人 ≠ 待办负责人则不计入**——例：待办「佳韵拆 10 条对标」，峰岚名下拆解完成不更新进度
- 无关联模块的待办：负责人手动勾选完成
