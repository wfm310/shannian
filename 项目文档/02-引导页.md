# 02-引导页

> 首次登录后的身份初始化：填写昵称与头像，完成后进入首页工作台，此后昵称/头像可在个人中心修改。

## 1. 页面场景与画板清单

| 端   | 画板       | 说明     |
| --- | -------- | ------ |
| PC  | 引导页 1920 | 居中单卡表单 |
| APP | 引导页 390  | 全屏表单   |

## 2. 字段真值

| # | 字段 | 必填 | 规则                                               |
| - | -- | -- | ------------------------------------------------ |
| 1 | 昵称 | 是  | 2\~12 字；即「负责人」下拉选项的来源（总纲规则 1）                    |
| 2 | 头像 | 是  | 预设色板圆 + 首字；色板按注册顺序自动分配（占位：峰岚=蓝紫 99,102,241、佳韵=红） |

## 3. 状态流转

| 状态  | 触发             | 系统动作                               |
| --- | -------------- | ---------------------------------- |
| 待填写 | 首次登录强制进入（不可跳过） | —                                  |
| 完成  | 提交昵称+头像        | 写入账号资料 → 首页工作台；给其他已有成员发「新成员加入」系统通知 |

## 4. 跨模块转化映射

无。昵称/头像写入账号体系，供所有模块的「负责人」字段与头像展示使用。

## 5. 消息通知触发点

| 事件      | 消息                      | 接收人    |
| ------- | ----------------------- | ------ |
| 新成员完成引导 | 「新成员 XX 加入了工作台」（system） | 全体其他成员 |

## 6. 演示数据

第三成员注册流程演示：昵称「小鹿」→ 色板第 3 色 → 进入工作台，负责人选项即变 3 人。

## 7. 全局规则引用

负责人=动态注册账号（规则 1，本页是选项的生成源头）；头像色按注册顺序分配（规则 1）。
