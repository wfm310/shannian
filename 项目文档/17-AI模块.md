# 17-AI 模块

> 本地 Ollama 辅助能力集（可选模块，设计预留接口）：6 项能力嵌入各模块，独立 AI 页承载对话与整理；关闭后其他功能不受影响。

> 细节来源：旧目录《A13-AI模块.md》能力矩阵 / 模型分配 / Prompt / 降级策略以该文档为准，本文只固化字段真值与集成点。

## 1. 页面场景与画板清单

| 端 | 画板 | 说明 |
|---|---|---|
| PC | AI 对话页 | 问答模式 + 整理模式（主题归纳 / 关联发现） |
| APP | AI 对话页 | 同构精简 |
| （嵌入） | 各模块内 AI 按钮 | 生成选题 / 辅助写作 / 推荐标签 / 摘要等，随宿主模块画板出 |

设置开关在 19-设置页（ai_enabled）。

## 2. 能力矩阵（6 项，摘要）

| 能力 | 输入 → 输出 | 模型 | 触发 |
|---|---|---|---|
| 选题创意生成 | 关键词 → N 个选题候选（默认 5，1-10 可配），采纳写入选题库（草稿） | qwen3:8b | 手动 |
| 脚本辅助写作 | 选题 → 框架模式 / 完整模式文案，采纳写入脚本框架库 | qwen3:8b | 手动 |
| 知识整理与问答 | 自然语言 / 选题范围 → 回答（标注引用来源）或归纳 / 关联建议 | deepseek-r1:7b | 手动 |
| 数据洞察分析 | 数据范围 → 洞察报告（关键发现/趋势/异常/机会建议），定时推送消息中心 | deepseek-r1:7b | 手动+定时 |
| 自动打标签+找关联 | 内容文本 → 标签建议（灵感 max5 / 对标 max10 / 问答 max5）+ 图关系边（存 Supabase 边表：SIMILAR_TO / RELATED_TO / ANSWERS） | qwen2:0.5b + qwen3:8b | 自动（灵感转化后 / 对标完成时 / 问答首次回答后） |
| 内容摘要/总结 | 单条或批量 → 要点+一句话总结 / 共性+差异+规律 | qwen3:8b | 手动 |

> 硬件口径（2026-08-31 实测机：i7-10700 / 16GB / 无独显，纯 CPU 推理）：qwen2:0.5b 与嵌入模型秒级可用；qwen3:8b 生成 200 字约 30~60 秒（生成类入口加「本地推理约 30~60 秒」预期提示）；deepseek-r1:7b 思考链 CPU 上 2~5 分钟，倾向其任务并入 qwen3:8b（低温度）——逐条过本模块时定最终模型分工。

模型参数与逐级降级链路（Ollama 不可用 → 提示不可用，**不调云端 API**）见旧档 A13 §2。

## 3. 字段真值

### 3.1 AI 任务记录（每次调用落一条）

| # | 字段 | 必填 | 说明 |
|---|---|---|---|
| 1 | 任务类型 | 是 | 6 能力枚举 |
| 2 | 宿主模块 | 是 | 来源模块标识 |
| 3 | 关联记录 ID | 否 | 宿主记录 |
| 4 | 输入摘要 | 是 | 输入内容截断 |
| 5 | 输出 | 是 | 结果全文（采纳后另存入目标模块） |
| 6 | 模型 | 是 | 实际使用的模型名 |
| 7 | 状态 | 是 | 成功 / 失败 / 已采纳 / 已丢弃 |
| 8 | 耗时 | 自动 | ms |
| 9 | 时间 | 自动 | 系统时间 |

### 3.2 AI 配置（存设置，见 19）

| 字段 | 值 |
|---|---|
| ai_enabled | 开 / 关（默认关；关闭后所有 AI 入口隐藏，功能不受影响） |
| 选题生成数量 N | 1-10，默认 5 |
| 洞察推送频率 | 每日 / 每周 / 关 |
| Ollama 地址 | http://localhost:11434 |

## 4. 状态流转

AI 任务记录：成功/失败（调用结束）→ 已采纳（用户采纳写入目标模块）/ 已丢弃。记录不可删除，可归档 ⚠（AI 任务记录是否参与归档，待逐条过确认）。

## 5. 消息通知触发点

| 事件 | 消息 | 接收人 |
|---|---|---|
| 数据洞察定时推送 | 「AI 洞察报告已生成」（module·ai-module） | 全体成员 |
| 模型加载失败 | 「AI 模型不可用，已降级」（system） | 触发者 |

## 6. 演示数据

## 7. 全局规则引用

本地 Ollama 禁云端 API（技术栈约束）；shadcn UI；AI 推荐均为「建议制」，采纳才写入目标模块（不自动改用户数据）。
