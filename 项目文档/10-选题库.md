## 2. 字段真值

### 2.1 新建表单

| 字段 | 必填 | 规则 |
|---|---|---|
| 选题标题 | 是 | 一句话选题（这条选题你会怎么讲）；填写后自动语义去重检测 |
| 选题备注 | 是 | 理解选题的一句话 |
| 标签 | 否 | 手动标签，上限 5 |
| 创建时间 / 创建人 | 自动 | 当前登录账号昵称 |

### 2.2 选题关联信息（转化时快照自动同步；手动新建可选，前两项建议填写）

| 字段 | 规则 |
|---|---|
| 选题来源 | 手动创建 / 对标拆解 / 问答收集 / 灵感记录 / 复盘回流 / 其他（自动关联）※统一「对标拆解」，旧文「对标分析」作废 |
| 来源关联ID | 可跳转来源记录 |
| 针对人群 | 身份 + 阶段 + 目标 + 卡点 + 情绪 五要素 |
| 解决什么问题 | — |
| 怎么解决的 | 可选填 |
| 需求类型 | 主动（用户主动寻找）/ 被动（你想让用户知道）/ 利他（跟用户利益挂钩） |
| 需求划分 | 显性 / 隐性 / 情绪心理 |
| 内容价值 | 实用干货 / 情绪共鸣 / 认知提升 |

### 2.3 定位匹配度评估（评估弹窗）

| 字段 | 必填 | 枚举 |
|---|---|---|
| 定位匹配度 | 是 | 高（跟我的受众人群非常匹配）/ 中（不是很匹配）/ 低（不匹配） |
| 需求强度 | 是 | 高（现在就想要解决）/ 中（现阶段不着急）/ 低（只是想看看） |
| 竞争热点 | 是 | 蓝海（3 分）/ 红海（1 分） |
| 内容定位 | 是 | 这条内容为了达到什么目的 |
| 优先级得分 | 自动 | 匹配度(1~3) + 强度(1~3) + 热点(1~3)，范围 3~9 |
| 优先级星级 | 自动 | 7-9 立即做 / 5-6 排期做 / 3-4 储备；**一票否决：定位匹配度=低时星级强制封顶「储备」** |
| 搁置原因 | 搁置时 | — |
| 文案内容参考 | 否 | 这条选题的文案打算怎么写；**已确认后转只读** |

### 2.4 列表卡与筛选

- 列表卡：选题标题 / 备注截断 / 状态色 / 星级 / 来源图标 / 标签前 3 / 相对时间 / 操作（详情/编辑/评估/转化）
- 搜索：标题 + 备注 + 文案内容参考
- 筛选：状态 / 来源 / 星级 / 标签 / 创建时间
- 排序：创建时间倒序（默认）/ 星级优先 / 得分降序

## 4. 跨模块转化映射

### 入（→ 选题库，快照拷贝）

| 来源 | 映射 |
|---|---|
| 对标拆解 | 最终凝练选题→标题；凝练出的文案→备注；人群/需求维度→关联信息 |
| 灵感记录 | 结论→标题（优先）；思考过程→文案内容参考；灵感标题→备注 |
| 问答收集 | 问题→关联信息；高赞回答→文案内容参考 |
| 复盘回流 | 复盘结论→标题 / 备注 |

### 出（选题库 →）

| 去向 | 映射 | 规则 |
|---|---|---|
| 内容生产 | 选题标题→任务标题；文案内容参考→文案内容；人群/问题/方法→参考上下文 | 已确认自动创建，1 选题 : 1 生产任务；生成 P1 待办「完成选题《xxx》的内容生产」 |
| 灵感记录 | 标题→灵感标题；备注→思考过程第一条；结论=空；分类默认「选题方向」⚠；标签 Ollama 建议 | 多次转化不影响选题状态；来源=选题库 |
