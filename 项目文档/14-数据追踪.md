> 记录每条已发布视频的流量与内容吸引力数据：5 个固定节点 + 长尾补录，四维指标体系，异常自动检测并触发复盘。

## 2. 追踪节点规则

| 节点 | 录入窗口 | 超出窗口 | 说明 |
|---|---|---|---|
| 2h | 2h~3h | 标记延迟 | 初始流量，判断初始推荐 |
| 24h | 24h~28h | 标记延迟 | 首日完整表现 |
| 3天 | 3天~3.5天 | 标记延迟 | 中期趋势 |
| 7天 | 7天~8天 | 标记延迟 | 核心评估周期 |
| 30天 | 30天~33天 | 标记延迟 | 长尾价值 |
| 长尾触发 | 用户自选 | — | 固定节点外二次录入 |

- 每节点采集**累计数据**（非增量），增量自动计算
- 到期自动生成数据录入待办；可提前手动录入

### 节点录入状态

| 状态 | 含义 |
|---|---|
| 待录入 | 待办已生成未录入 |
| 已录入 | 窗口内完成 |
| 延迟录入 | 超窗口补录（记实际值；历史基准计算时权重 0.5；趋势图空心点标注） |
| 已跳过 | 用户放弃该节点，停止提醒 |

始终允许补录，不锁死节点。

## 3. 字段真值（四维指标体系）

### 3.1 流量数据（手动，累计）

| 字段 | 必填 |
|---|---|
| 播放量 | **是（唯一必填）** |
| 点赞量 / 评论量 / 分享量 / 收藏量 / 累计涨粉量 | 否 |

### 3.2 内容吸引力（手动）

2s跳出率 / 5s完播率 / 平均播放时长（秒）/ 完播率 —— 均选填。

### 3.3 观众参与度（自动计算，只读）

点赞率 / 评论率 / 分享率 / 收藏率 = 对应量 ÷ 播放量，录入后实时显示。

### 3.4 搜索关键词（手动，Top N 默认 15，N 可配 5~30）

| 字段 | 说明 |
|---|---|
| 看到作品的搜索词 | 词 + 频次，反映 SEO 与推荐方向 |
| 看完后常搜的词 | 词 + 频次，反映被激发的后续需求 |

跨节点自动去重，同一词保留最新频次。

### 3.5 系统字段

关联发布记录（必填）/ 追踪节点 / 追踪时间 / 数据来源（手动/自动拉取）/ 异常标记（自动）/ 节点录入状态（自动）。

## 4. 录入体验规则

1. 手动字段共 12 个（流量 6 + 吸引力 4 + 搜索词 2 组），参与度 4 项自动算
2. 分维度折叠：默认展开「流量数据」，其余折叠
3. 只有播放量必填；补录时已有字段预填
4. 新节点流量数据预填上一节点值（累计只增不减，往上调整）
5. 不做粘贴解析器（后台结构易变）；纯数字输入框 + Tab 跳转 + 实时比率反馈

## 5. 异常检测规则

- 基准：同一节点同一指标的历史均值（延迟数据权重 0.5）
- 最少数据量：同节点同指标历史 ≥5 条才启用，不足跳过
- 双向阈值：**异常高 ≥ 均值 ×2.0（要学）/ 异常低 ≤ 均值 ×0.5（要查）**
- 触发动作：写入消息通知（数据变更提醒）+ 自动创建 P2 复盘待办
- 搜索关键词为定性数据，不参与检测

## 6. 多维度对比

| 维度 | 匹配逻辑 | 状态 |
|---|---|---|
| 同期发布 | 发布时间 ±7 天 | 可启用 |
| 同框架对比 | 相同脚本框架 | 留接口，待数据就绪 |
| 同标题公式 | 相同 T1~T5 | 留接口，待数据就绪 |
| 自定义 | 手动选择 | 可启用 |

- 对比视频 2~5 个；图表：趋势折线 / 节点柱状 / 明细表格；异常点高亮
- 默认指标：播放量、完播率、点赞率、累计涨粉量，可切换任意数值字段
