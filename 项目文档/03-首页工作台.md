## 3. 交互规则

1. 所有卡片点击 = 跳转对应模块页面/详情；工作台不新增/编辑任何记录
2. 快记单触点直达：PC 顶栏快记按钮 / N 键，APP 快记球（总纲原则 3）
3. 各卡数字 = 各模块统计快照（下拉刷新/进入时刷新，不做实时推送）
4. 问候语按时段：早上好 / 下午好 / 晚上好 + 昵称

## 4. 消息通知触发点

工作台不产生独立消息；铃铛未读数与消息页共用同一数据源（见 05-消息通知）。
