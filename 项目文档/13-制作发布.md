## 2. 标题公式（T1~T5，用户确认的核心定义）

标题双任务：SEO（让算法知道推给谁）+ 点击率（让用户愿意点进来）。必须包含 1~2 个核心搜索词，关键词尽量前置。字段旁展示公式提示，选一个套用。

| 编号 | 结构 | 示例 | 适用 |
|---|---|---|---|
| T1 | 人群+痛点+解决方案暗示 | "带货新人别再乱选品了，这3步帮你避开90%的坑" | 干货教学类 |
| T2 | 反常识/颠覆认知+悬念 | "我劝你千万别做短视频带货……除非你看完这条" | 纠错对比类 |
| T3 | 数字+结果+时间 | "7天出了第一单，我只做了这1件事" | 案例故事类 |
| T4 | 关键词前置+问题句式 | "短视频带货怎么选品？新手最容易忽略的1个细节" | 搜索SEO型 |
| T5 | 情绪共鸣+身份认同 | "做了3个月带货还没出单的人，我懂你的焦虑" | 共鸣信任类 |

## 3. 话题标签「3+1+1」结构（用户确认的核心定义）

| 位置 | 类型 | 作用 |
|---|---|---|
| 第 1~2 个 | 赛道大词 | 让算法知道你在哪个赛道（基本固定） |
| 第 3 个 | 内容精准词 | 精准匹配本条主题 |
| 第 4 个 | 人群词/场景词 | 锁定目标用户（按选题微调） |
| 第 5 个 | 热点/活动词 | 蹭额外流量（看时效） |

常用标签库在设置模块维护；发布时**弹窗勾选**，不手动输入。

## 4. 字段真值

| 字段 | 必填 | 规则 |
|---|---|---|
| 视频标题 | 是 | 含 1~2 核心搜索词，前置；旁展示 T1~T5 |
| 标题公式 | 否 | T1~T5，仅记录留存 |
| 描述文案 | 是 | 发布到抖音的描述/简介 |
| 话题标签 | 是 | 3+1+1 结构，标签库弹窗勾选 |
| 文案内容 | 是 | 该视频完整文案 |
| 发布平台 | 是 | 抖音（暂不多平台预留） |
| 发布时间 | 是 | 实际发布时间，精确到时分，手动填写 |
| 视频链接 | 否 | 创建后**允许补充一次**（唯一可编辑字段） |
| 发布模式 | 是 | 标准 / 即兴 |
| 关联选题 | 否 | 即兴可空 |
| 关联框架 | 否 | 只读关联展示 |
| 关联生产任务 | 条件必填 | 标准必填；即兴选填 |
| 关联灵感ID | 条件必填 | 即兴从灵感转化时必填（溯源） |
| 发布状态 | 自动 | 待发布 / 已发布（按视频链接自动流转） |
| 数据追踪状态 | 自动 | 待追踪 / 追踪中 / 已复盘 |
| 创建时间 | 自动 | — |

## 6. 跨模块转化映射

| 方向 | 规则 |
|---|---|
| 内容生产 → 本模块 | 待发布阶段移交自动创建：选题标题→视频标题初始（可按标题公式重写）、文案内容参考→文案内容、关联生产任务必填 |
| 即兴凭空创建 | 无上游来源，溯源到此为止 |
| 灵感 → 本模块（即兴） | 必须记录关联灵感ID |
| 本模块 → 数据追踪 | 已发布自动创建追踪任务 |
| 本模块 → 灵感回流 | 即兴完整文案 + 创作过程自动回流灵感库（标记「即兴创作」） |
