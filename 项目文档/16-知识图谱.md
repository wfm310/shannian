# 16-知识图谱

> 所有模块最终沉淀的知识库：内容图谱（找答案）+ 标签图谱（找问题）双视图，力导向可交互探索，AI 对话式检索。

> 收编自：A12-大脑知识库（完整技术设计，本档保留设计相关核心；Cypher/SQL 代码级实现由 L-page 开发阶段产出）。术语统一「知识图谱」，废弃「大脑知识库」。

## 1. 页面场景与画板清单（预估 4 张）

| 端 | 画板 | 说明 |
|---|---|---|
| PC | 图谱全屏 | 内容图谱默认视图（力导向） |
| PC | 节点详情侧滑面板 | 单击节点右侧滑出，含跳转源模块 |
| APP | 图谱 · 简化列表 | 移动端以列表为主，图谱为高级入口 |
| APP | 节点详情页 | |

结构可复用闪念池星图的视觉语言（总纲已注明），但语义不同：闪念星图=活跃工作区；知识图谱=沉淀档案（弱化活跃感，突出知识结构）。

## 2. 硬约束（技术底座）

- 存储（2026-08-31 用户确认：**Supabase 单云方案，不用 Neo4j**）：图数据存 Supabase PostgreSQL——节点表 + 边表 + 递归 CTE 多跳查询；pgvector 语义向量（nomic-embed-text，768 维）；内容与图谱同库，同步/鉴权/备份一体
- 可视化：Sigma.js + WebGL；子图渲染单元 500-2000 节点
- AI 检索：Ollama qwen3:8b 本地 RAG（禁用云端 LLM）

## 3. 内容图谱 Schema

### 3.1 节点类型（9 种，标签只存在于标签图谱）

| 节点类型 | 来源模块 |
|---|---|
| 闪念 FlashIdea | 闪念池 |
| 对标拆解 Benchmarking | 对标拆解 |
| 选题 Topic | 选题库 |
| 问答 QA | 问答收集 |
| 灵感 Inspiration | 灵感记录 |
| 脚本框架 ScriptFramework | 脚本框架 |
| 脚本内容 ScriptContent | 内容生产（生产任务不作为节点，只保留脚本内容） |
| 发布记录 PublishRecord | 制作发布 |
| 复盘 Review | 复盘记录 |

节点通用属性：node_id / node_type / title / summary（前 200 字）/ source_module / source_record_id（跳转源记录）/ tags / status / created_at / updated_at；各类型附加筛选属性（如 Topic 的 priority_star、FlashIdea 的 keywords）。

### 3.2 边类型（8 种，确定性→柔性）

| 边类型 | 定义 | 方向 | 权重 |
|---|---|---|---|
| TRANSFORMED_TO 转化为 | A 直接转化为 B（快照复制） | 闪念→灵感、对标→选题、对标→灵感、问答→选题、灵感→选题/框架 | 1.0 |
| PRODUCED_AS 生产为 | 选题确认进入生产产出脚本内容 | 选题→脚本内容 | 1.0 |
| APPLIES 调用框架 | 脚本内容调用了某框架 | 脚本内容→脚本框架 | 1.0 |
| PUBLISHED_AS 发布为 | 脚本内容发布生成发布记录 | 脚本内容→发布记录 | 1.0 |
| REVIEWED_FROM 复盘于 | 基于发布记录复盘 | 发布记录→复盘 | 1.0 |
| REFERENCES 引用 | 创作中显式引用其他知识 | 脚本内容→对标拆解等 | 0.8 |
| DERIVED_FROM 衍生 | 复盘经验提炼新选题 | 复盘→选题 | 0.9 |
| RELATED_TO 关联 | 语义相似（source=semantic）/手动关联（source=manual） | 任意节点 | 0.3-0.7 |

> ⚠ 统一说明：A6/A5 旧档中转选题写「PRODUCED_AS 关系」，与 A12 Schema（转化=TRANSFORMED_TO）冲突，按 A12 统一为 TRANSFORMED_TO；确定性关系随业务自动产生、不可手动删除。

### 3.3 标签图谱

- 标签节点统一 Tag 类型，tag_type 区分：system（系统固定：对标拆解/问答/选题/灵感/脚本框架/发布记录/复盘）/ topic（主题）/ keyword（闪念 Ollama 关键词实体）/ derived（对标需求分析派生）/ type（框架类型、展现形式）
- 共现关系 CO_OCCURS_WITH：两标签同时出现在一条内容即共现一次；存储共现次数（边粗细）+ Jaccard 强度（筛选阈值）；无方向

## 4. 自动聚合规则

### 4.1 同步触发

| 模块 | 触发 | 特殊说明 |
|---|---|---|
| 闪念池 | 创建时同步一次 | 闪念不可编辑，仅创建同步 |
| 对标拆解 | 创建/更新/状态/标签变更 | 状态变为已拆解后节点锁定只读；转化建 TRANSFORMED_TO |
| 选题库 | 同上 | 确认生产建 PRODUCED_AS |
| 问答收集 | 同上 | 转选题建 TRANSFORMED_TO |
| 灵感记录 | 同上 | 闪念来源建 TRANSFORMED_TO（闪念→灵感）；转选题/框架建 TRANSFORMED_TO |
| 脚本框架 | 创建/版本更新 | 被脚本调用建 APPLIES |
| 脚本内容 | 创建/更新/状态变更 | 建 PRODUCED_AS + APPLIES |
| 发布记录 | 创建 | 建 PUBLISHED_AS |
| 复盘记录 | 创建/更新 | 建 REVIEWED_FROM；提炼新选题建 DERIVED_FROM |

### 4.2 自动打标签（各模块系统标签 + 主题标签规则）

闪念=无标签字段仅 Ollama 关键词实体；对标拆解=系统标签+最多 10 个；选题/问答/灵感=系统标签+最多 5 个（推荐不可删改）；框架=类型标签；脚本内容=继承来源选题标签；发布=话题标签（常用标签库）；复盘=继承被复盘记录标签+提炼标签。

### 4.3 语义自动关联（RELATED_TO semantic）

embedding 变化时异步：pgvector 检索 → 相似度 ≥0.75 → 取 Top 5 → 已有确定性关系的不重复建 → 边属性 source=semantic + similarity_score；内容更新时删除旧语义边重算。

## 5. 查询与检索

| 方式 | 规则 |
|---|---|
| 关键词搜索 | Supabase 全文检索（ts_rank），按节点类型搜对应字段（如 Topic=标题+备注+内容参考）；点击结果图谱定位或看详情 |
| 标签+维度筛选 | 内容图谱：节点类型/标签/标签类型/时间/状态/星级/质量标记；标签图谱：标签类型/使用次数/共现次数 |
| AI 对话式检索 | qwen3:8b RAG：意图解析 → 三路并行（全文+语义+图谱 1-2 跳）→ 融合去重 Top 10 → 生成回答+引用来源 → 图谱联动高亮；AI 不写查询语句，用 5 个查询模板（类型+标签/关联探索/语义相似/内容空白分析/跨链路追溯） |
| 创作时推荐 | 侧边面板非侵入：语义相似+标签重叠+图谱遍历三路，确定性关系>语义>标签重叠排序，Top 10，显示推荐原因 |

## 6. 图谱交互

| 操作 | 行为 |
|---|---|
| 悬停 | tooltip：标题/类型/状态/标签数/关联数 |
| 单击 | 高亮 1 跳邻居，其余降透明度；右侧信息面板（跳转源模块） |
| 双击 | 懒加载展开 2 跳邻居 |
| 右键 | 查看详情/继续展开/手动添加关联/聚焦模式 |
| 两图联动 | 内容图谱点标签→切标签图谱高亮；标签图谱双击→切内容图谱按标签筛选（找答案↔找问题） |
| 布局 | 力导向（默认）/ 层级（生产链路）/ 时间布局 |
| 缩放 | 滚轮平滑缩放，远视图隐藏标签 |

### 子图提取（性能核心）

筛选种子集 → 超过 1500 按度数+时间加权裁剪 → 1 跳邻居扩展至 1000-1500 → 超 2000 裁低权重叶子 → 参数：最小 500（提示放宽筛选）/ 目标 1000-1500 / 最大 2000；大结果集分页加载。

## 7. 视觉映射（⚠ 色板待设计）

- 节点大小=关联数（内容图谱）/使用次数（标签图谱）；边粗细=权重/共现次数；确定性关系实线深色、柔性虚线浅色
- ⚠ 节点类型 9 种 > 主题色相 4 个，需扩展「图谱辅助色板」（L3 层新增，待逐条过时确认）：原则=类型色可辨识、与状态色不冲突
