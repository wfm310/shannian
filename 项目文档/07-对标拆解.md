## 2. 字段真值

### 2.1 流程与状态规则

1. 列表页快速记录基础信息 → 状态「拆解中」
2. 详情页基础信息**只读**；**谁来负责谁来拆**，非负责人只读
3. 状态不能自主编辑，跟随拆解进度实时更新
4. 时间显示：未完成显示新建时间；完成显示完成时间
5. 详情三段结构：表头（基础信息·固定只读）+ 内容区（四维度）+ 表底（取消 / 下一步·固定不动）

### 2.2 对标视频基础信息（表头 · 只读）

| 字段         | 说明                                      |
| ---------- | --------------------------------------- |
| 对标视频标题     | —                                       |
| 原视频 URL 链接 | 可点击打开                                   |
| 刷到时的位置（来源） | 推荐页 / 搜索页 / 抖音指数 / 其他                   |
| 负责人        | 系统注册账号（当前占位：峰岚 / 佳韵）；**谁来负责谁来拆**，非负责人只读 |
| 视频文案内容     | 原文完整保存                                  |

### 2.3 维度 1 · 人群：做给谁看的？

| 字段 | 引导问题           |
| -- | -------------- |
| 身份 | 她现在是一个什么样的身份？  |
| 阶段 | 处在一个什么样的阶段？    |
| 目标 | 想要达成一个什么样的效果？  |
| 卡点 | 到底卡在了哪个环节上？    |
| 情绪 | 她现在的情绪状态是怎么样的？ |

### 2.4 维度 2 · 需求：解决了什么问题？

| 分组    | 选项                   |
| ----- | -------------------- |
| 需求指向  | 主动 / 被动 / 利他         |
| 需求划分  | 显性 / 隐性 / 情绪心理       |
| 内容价值  | 实用干货 / 情绪共鸣 / 认知提升   |
| 一句话总结 | 这个视频解决了用户的什么核心问题（必填） |

### 2.5 维度 3 · 内容：什么形式和结构？

- 展现形式（多选）：真人出镜口播 / 画面+旁白 / 剧情演绎 / 动画·文字辅助 / 其它
- 内容结构类型（单选，**与「11-脚本框架」5 类型共享同一套定义**）：

| 类型          | 流程                            |
| ----------- | ----------------------------- |
| ① 标准干货型（主力） | 抛观点 → 举例佐证 → 给方法 → 引导         |
| ② 故事案例型     | 抛悬念/场景 → 展开冲突 → 揭示转折/方法 → 引导  |
| ③ 纠错对比型     | 展示错误做法 → 为什么错 → 正确做法 → 引导     |
| ④ 清单盘点型     | 抛主题 → 第1点 → 第2点 → 第3点 → 总结+引导 |
| ⑤ 问答拆解型     | 模拟提问 → 分析为什么 → 给解答 → 引导       |

### 2.6 维度 4 · 自身：能不能用上？

三个问题依次回答；前两个是「选择 + 联动必填文本」结构，选项决定联动哪个文本框：

| 问题        | 选择         | 联动文本框（选后必填）           |
| --------- | ---------- | --------------------- |
| 我做得到吗？    | 做得到，可借鉴    | 「哪里能做到、哪里能借鉴」         |
| <br />    | 做不到，放弃     | 「卡点在哪里」               |
| 需求解决透不透？  | 很透，可借鉴     | 「哪里讲透了」               |
| <br />    | 不透，有机会点    | 「哪里没讲透」               |
| 差异化层次     | 人无我有       | <br />                |
| <br />    | 人有我优       | <br />                |
| <br />    | 人优我专       | <br />                |
| <br />    | 人专我抄改超     | <br />                |
| 竞争热度      | 红海         | <br />                |
| <br />    | 蓝海         | <br />                |
| 差异化机会是什么？ | （纯文本，直接填写） | 换角度的具体点；如果是你来做，你会怎么做？ |
