## 2. 业务逻辑

1. **一问一答**：每条记录只含一个问题和一个答案
2. **答案可迭代**：每次修改生成新版本（v1 无需修改说明，v2 起必填），保留完整时间线，支持任意两版本逐行对比，不支持回退
3. **多来源**：观众评论 / 自问自答 / 搜索热点 / **闪念转入** ⚠（A5 原文缺此枚举，按闪念归类三选一规则补入；映射见第 4 节）；来源详情按来源类型动态展示
4. **问题去重**：pgvector 语义相似度实时检测（防抖）；非阻断提醒，>90% 强提醒需二次确认；检测范围排除已转选题和已归档
5. **可转选题**：终态，不可二次转化（符合总纲规则 4）；快照拷贝转后独立编辑
6. **质量标记**：已回答/已优化状态下可标记「已完善 / 待补充」；Ollama 自动评估建议+用户手动；待补充生成 P1 待办；转选题时若待补充则非阻断提醒
7. **创建后只读**：问题内容和问题来源创建后只读
8. 当前阶段不做批量操作

## 3. 状态流转

| 当前 | 触发 | 下一 | 系统动作 |
|---|---|---|---|
| 待回答 | 新建问题 | — | 同步知识图谱，生成 embedding |
| 待回答 | 首次填写答案 | 已回答 | 生成 v1，Ollama 推荐标签+评估质量 |
| 已回答 | 补充优化答案 | 已优化 | 新版本（修改说明必填），Ollama 评估，embedding 更新 |
| 已优化 | 继续优化 | 已优化 | 版本递增 |
| 已回答/已优化 | 转为选题 | 已转选题（终态） | 快照拷贝，图谱追加 TRANSFORMED_TO 边 |
| 待回答/已回答/已优化 | 手动归档 | 已归档（终态） | 保留记录，停止提醒 |

## 4. 字段真值

| 字段 | 必填 | 说明 |
|---|---|---|
| 问题内容 | 是 | 一条记录一个问题；创建后只读；用于去重与 embedding |
| 问题来源 | 是 | 观众评论 / 自问自答 / 搜索热点 / 闪念转入；创建后只读 |
| 来源详情 | 否 | 动态展示：观众评论→评论原话；搜索热点→搜索关键词；自问自答→触发场景说明；闪念转入→「你的想法」原文 |
| 答案内容 | 否 | Markdown 实时预览+语法提示；当前版本内容 |
| 答案版本号 | 自动 | v1 起，优化递增 |
| 版本时间线 | 自动 | 每版本内容/时间/修改说明 JSON；支持版本对比 |
| 质量标记 | 否 | 已完善 / 待补充 |
| 标签 | 否 | Ollama 推荐（不可删改）+手动（可增删改）；上限 5；系统标签「问答」不计上限不可删 |
| 转选题关联 ID | 自动 | 转选题后记录 |
| 归档时间 / 创建时间 / 最后更新 | 自动 | — |

### 闪念转入映射 ⚠（需逐条过确认）

| 问答字段 | 来源 | 规则 |
|---|---|---|
| 问题内容 | 闪念内容 | 预填，可编辑 |
| 问题来源 | — | 固定「闪念转入」 |
| 来源详情 | 「你的想法」 | 作为触发场景说明带入 |
| 答案内容 | — | 空 |

## 8. 全局规则引用

无删除仅归档；快照拷贝；知识图谱同步（QA 节点 + TAGGED_WITH / TRANSFORMED_TO 关系；embedding 基于「问题+答案」组合，答案变更时重新生成）；Ollama：标签推荐（首次答案完成触发）+ 答案完整度评估。

2. A5 状态色苹果系 → 已重映射主题 token
3. 「大脑知识库」→ 统一「知识图谱」
