## 2. 复盘类型与触发机制

### 2.1 两种类型

| 类型 | 覆盖范围 |
|---|---|
| 单条视频复盘 | 该视频数据表现 + 创作过程 |
| 周期性汇总复盘 | 数据汇总 + 工作回顾（日/周/月三周期） |

### 2.2 周期性复盘

| 周期 | 生成时机 | 侧重 |
|---|---|---|
| 日报 | 每天 20:00 | 工作回顾为主；数据轻量（当日发布视频的播放量/2s跳出率/5s完播率/平均播放时长） |
| 周报 | 每周一早上 | 数据汇总 + 工作回顾，完整五模块，环比上周 |
| 月报 | 每月 1 号 | 完整五模块 + 环比上月 + 横向竖向对比 |

### 2.3 单条视频复盘触发

| 方式 | 条件 |
|---|---|
| 异常自动触发 | 数据追踪异常检测命中（24h / 7天 / 30天节点判定）⚠ |
| 爆款自动触发 | 播放量 > 历史均值 ×3 |
| 手动创建 | 不限条件 |

⚠ **需用户裁决的并存规则**：旧 A11 另有一套固定阈值（2s跳出率>60%、5s完播率<30%、播放量明显低于同期均值），与 A10 的统计异常检测（均值×2.0 / ×0.5）重叠。本文按「**统一走 14-数据追踪的异常检测触发 + 爆款×3 触发**」处理，固定阈值作废；若你想保留固定阈值作为兜底硬线，告诉我再改回双轨。

- 同一视频在不同节点可各自触发独立复盘记录，独立流转
- 触发即创建「待复盘」记录 + P1 待办（关联该复盘）

## 3. 字段真值

### 3.1 基础字段

| 字段 | 必填 | 规则 |
|---|---|---|
| 复盘标题 | 自动可改 | 单条：【单条视频复盘】视频标题-节点；周期：【周报】2026年第33周复盘 |
| 复盘类型 | 是 | 单条视频复盘 / 周期性汇总复盘 |
| 复盘周期 | 条件 | 日/周/月（周期性必填） |
| 关联对象 | 是 | 单条=发布记录ID；周期=时间段 |
| 触发方式 | 是 | 异常触发 / 爆款触发 / 周期自动生成 / 手动创建 |
| 触发节点 | 条件 | 24h / 7天 / 30天（单条自动触发时） |
| 负责人 | 是 | 峰岚 / 佳韵 |
| 状态 | 自动 | 待复盘 / 复盘中 / 已完成 |
| 创建时间 / 完成时间 | 自动 | — |

### 3.2 五模块结构（单条复盘表单顺序）

| # | 模块 | 自动填充 | 用户填写 |
|---|---|---|---|
| 1 | 数据表现回顾 | 数据快照（触发节点全量数据，只读） | 数据简评（日报选填，其余必填） |
| 2 | 做得好的 | — | 多条目：维度（内容表现/创作过程/运营策略/工作状态/综合）+ 描述 |
| 3 | 做得不好的 | — | 同上 |
| 4 | 可复用经验 | 标签（Ollama 建议） | 多条目：经验标题 + 经验内容（背景+做法+效果）+ 分类（内容创作/运营策略/流程效率/其他）+ 适用场景 |
| 5 | 下一步行动 | — | 多条目：行动内容 + 优先级（P0~P3）+ 截止日期 + 关联模块 ⚠ |

- 表单顶部只读上下文卡：脚本框架 / 对标参考 / 标题公式
- 同视频多次复盘时展示历史复盘摘要（只读）
- 手动创建时数据快照拉取最新可用数据
- 已完成后可「补充修改」（保持已完成）：经验与行动**只能新增和修改，不可删除**

### 3.3 周期复盘对比区（自动只读）

横向-同期视频 / 横向-同框架 / 横向-同标题公式 / 横向-同分类 / 竖向-历史趋势（默认近 3 个月）/ 环比。周报环比上周，月报环比上月。

## 4. 状态流转

| 状态 | 色（主题 token） | 触发 → 下一状态 | 系统动作 |
|---|---|---|---|
| 待复盘 | 黄 250,204,21 | 异常/爆款/周期/手动触发 | 生成 P1 复盘待办 |
| 复盘中 | 紫 139,92,246 | 开始填写 | 记录开始时间 |
| 已完成 | 青绿 46,212,168 | 完成必填模块保存 | 经验回流知识图谱；行动生成待办；复盘待办自动完成 |

- 全程系统驱动不可手动改状态；不可跳过、不可删除；已完成是终态（可补充修改）；重新复盘=新建一条

## 5. 产出回流规则

### 5.1 经验 → 知识图谱

每条可复用经验回流为一个知识节点（节点类型=复盘经验）：经验标题→标题、经验内容→内容、分类→分类标签、适用场景→上下文。

### 5.2 行动 → 今日待办

| 行动字段 | → 待办字段 |
|---|---|
| 行动内容 | 任务名称 |
| 优先级（用户手选 P0~P3） | 优先级 |
| 截止日期 | 截止日期 |
| — | 任务来源=复盘；负责人=复盘负责人 |

⚠ **与总纲的冲突（需用户裁决）**：总纲规定待办「关联模块」仅 3 个（对标拆解/选题库/制作发布），但旧 A11 的行动关联模块还包含「内容生产流程/脚本框架库」。本文按总纲 3 个处理；原「框架迭代」机制改为：行动条目可勾选「框架迭代」标记（替代靠关联模块触发）→ 勾选后对应脚本框架显示「复盘建议迭代」标记 + 待办内容含复盘发现的问题，待办处理完标记解除。

### 5.3 待办联动

| 待办 | 数量 | 联动 |
|---|---|---|
| 复盘待办（触发时生成） | 1 条 | 复盘完成自动标记已完成 |
| 行动待办 | N 条 | 独立流转，不受复盘状态影响 |
