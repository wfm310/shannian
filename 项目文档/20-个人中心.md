# 20-个人中心

> 账号资料与个人统计：头像/昵称可改（全局详情只读的明确例外），各模块「我的记录」数一览，退出登录。

## 1. 页面场景与画板清单

| 端 | 画板 | 说明 |
|---|---|---|
| PC | 个人中心页 | 左账号卡 + 右统计卡 + 操作项 |
| APP | 个人中心页 | 账号卡 + 统计横滑 + 列表操作项 |

## 2. 字段真值

### 2.1 账号卡

| 字段 | 规则 |
|---|---|
| 头像 | 可改（上传 / 色板圆+首字，同引导页 02） |
| 昵称 | 可改（2~12 字）；改后所有模块「负责人」选项同步 ⚠ 历史记录里的旧昵称是否跟随改（建议：展示跟随账号，不做快照）待逐条过确认 |
| 注册时间 | 只读 |

### 2.2 我的记录统计（只读数字卡）

| 项 | 口径 |
|---|---|
| 我的闪念 | 闪念池中创建人=我的记录数 |
| 我的拆解 | 负责人=我的对标拆解数 |
| 我的灵感 / 选题 / 脚本 / 文案 / 发布 / 复盘 | 各模块创建人=我的记录数 |
| 我的待办完成 | 待办负责人=我且已完成的历史累计 |

### 2.3 操作项

| 操作 | 说明 |
|---|---|
| 退出登录 | 返回登录页（01） |
| 账号切换 | 退出后换账号登录（不做免密切换 ⚠ 待确认） |
| 进入设置 | 跳转 19 |

## 3. 状态流转

无记录状态；资料修改即时生效。

## 4. 跨模块转化映射

无（统计为实时查询，非快照）。

## 5. 消息通知触发点

无。

## 6. 演示数据

峰岚：闪念 23 · 拆解 12 · 灵感 15 · 选题 9 · 发布 7 · 复盘 5；待办完成 42。

## 7. 全局规则引用

详情只读例外=昵称/头像可改（规则 8 例外，对齐 02 引导页字段）；负责人=动态注册账号（规则 1）；无删除（规则 6，退出登录≠注销账号）。
