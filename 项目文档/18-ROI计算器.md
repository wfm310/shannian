# 18-ROI 计算器

> 投入产出测算工具（内容暂定）：单条视频 / 月度两种口径，算「这条内容到底值不值」；工具类模块，记录可保存复看。

## 1. 页面场景与画板清单

| 端 | 画板 | 说明 |
|---|---|---|
| PC | ROI 计算器页 | 左输入区 + 右结果卡（ROI 大数字焦点）+ 历史记录列表 |
| APP | ROI 计算器页 | 输入抽屉 + 结果卡 + 历史列表 |

## 2. 字段真值

| # | 字段 | 必填 | 规则 |
|---|---|---|---|
| 1 | 计算口径 | 是 | 单条视频 / 月度 |
| 2 | 关联发布记录 | 单条口径时必填 | 选择制作发布的某条记录（自动带入其数据追踪数据） |
| 3 | 拍摄时长 | 是 | 小时（h） |
| 4 | 剪辑时长 | 是 | 小时（h） |
| 5 | 其他成本 | 否 | 元（道具/投流/设备折旧，手填合计） |
| 6 | 平台收益 | 是 | 元（创作激励/带货/gmv，手填合计） |
| 7 | 涨粉数 | 否 | 自动取数据追踪，可改 ⚠ 是否自动带入待确认 |
| 8 | 时薪基准 | 是 | 元/h（设置页可配默认值） |
| 9 | ROI 结果 | 自动 | 公式见下 |

**ROI 公式（暂定）**：投入 = (拍摄 + 剪辑) × 时薪 + 其他成本；产出 = 平台收益 + 涨粉数 × 单粉价值（单粉价值 ⚠ 待定，暂定设置页可配）；ROI = 产出 ÷ 投入，结果卡大数字展示，>1 青绿 / <1 黄。

## 3. 状态流转

计算记录：已保存 → 已归档（手动；无其他流转，纯工具记录）。

## 4. 跨模块转化映射

来源：关联发布记录（只读引用其数据，非快照——记录更新 ROI 可重算 ⚠ 与「快照拷贝独立编辑」原则的差异：这里是实时引用，待逐条过确认）；去向：无。

## 5. 消息通知触发点

无。

## 6. 演示数据

单条视频「开头 3 秒定生死」：拍摄 2h + 剪辑 3h + 时薪 50 + 其他 0 = 投入 250；收益 120 + 涨粉 186 × 0.5 = 产出 213；ROI 0.85（黄）。

## 7. 全局规则引用

无删除仅归档（规则 6）；关键数字视觉焦点（原则 4）；状态色 token（规则 5）。
